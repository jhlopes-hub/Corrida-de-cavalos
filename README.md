# 🏇 Corrida dos 45 Anos

Competição entre:

- EBAY
- SMMT
- MU
- ASTS
- MRVL
- ACGL

## Regras

Data de partida: 06/08/2026

Cada ação inicia a corrida na posição zero.

A classificação é calculada pela valorização percentual acumulada desde o preço registado no início da corrida.
